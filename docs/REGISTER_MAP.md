# Register Map

## Confirmed Holding Registers

| Register | Description |
|----------|-------------|
| 1640 | Fast current (RW, x100 A) |
| 1641 | Mode (0=Fast,1=Eco,2=Green) |

## Confirmed Input Registers

| Register | Description |
|----------|-------------|
| 0 | Grid voltage (x100 V) |
| 12 | Grid frequency (x100 Hz) |
| 4 | Charge current (candidate, x100 A) |
| 8 | Charge power (candidate, W) |
| 18 | Charger state (candidate) |
| 21 | Session flag (candidate) |
